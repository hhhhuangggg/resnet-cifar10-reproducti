# 阶段七：亲自训练操作与实验记录指南

## 一、本阶段要完成什么

你将亲自在 CIFAR-10 上分别训练：

1. PlainNet-20，5 个 epoch；
2. ResNet-20，5 个 epoch；
3. 对比两者的 loss、accuracy、收敛趋势和训练稳定性。

两组实验只改变网络是否具有残差捷径，其他默认条件相同：

| 项目 | 设置 |
|---|---:|
| 随机种子 | 42 |
| batch size | 128 |
| 初始学习率 | 0.1 |
| 优化器 | SGD |
| momentum | 0.9 |
| weight decay | 0.0001 |
| 训练轮数 | 5 |
| 设备 | CUDA GPU |

这 5 轮是流程验证和初步比较，不等同于论文的 64k iterations 正式训练。

## 二、为什么使用两个 Anaconda Prompt

| 窗口 | 用途 | 是否执行训练 |
|---|---|---|
| Prompt A | 启动 PlainNet/ResNet 训练，查看 tqdm 和每轮总结 | 是 |
| Prompt B | 启动 TensorBoard 服务 | 否 |
| 浏览器 | 打开 TensorBoard 页面，读取 `runs` 中的日志 | 否 |

`http://localhost:6006` 是你自己电脑上的 TensorBoard 页面。它只展示日志，不会启动训练，也不会把数据上传到互联网。

## 三、训练前检查

在 Prompt A 中逐行执行：

```bat
conda activate resnet-paper
cd /d "E:\文档\resnet复现"
python --version
python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0))"
python -m pytest -q
```

预期：

- Python 为 3.11；
- CUDA 为 `True`；
- GPU 为 `NVIDIA GeForce RTX 3060 Laptop GPU`；
- 自动测试全部通过。

## 四、启动 TensorBoard

打开 Prompt B，执行：

```bat
conda activate resnet-paper
cd /d "E:\文档\resnet复现"
tensorboard --logdir runs
```

保持 Prompt B 不关闭，然后在浏览器打开：

```text
http://localhost:6006
```

训练开始后，TensorBoard 每个完整 epoch 会出现一个新数据点。可重点查看：

- `Loss/train`：训练集平均损失；
- `Loss/test`：测试集平均损失；
- `Accuracy/train`：训练集准确率；
- `Accuracy/test`：测试集准确率；
- `LearningRate`：当前学习率；
- `Time/epoch_seconds`：每轮耗时。

## 五、训练 PlainNet-20

在 Prompt A 中执行：

```bat
python train.py --model plain20 --epochs 5
```

运行时观察：

- 进度条的 batch 数是否持续增加；
- loss 是否为有限数字，没有 `nan` 或 `inf`；
- accuracy 是否逐渐脱离约 10% 的随机猜测水平；
- 每轮结束是否打印训练集和测试集的完整总结；
- TensorBoard 是否增加一个新点；
- Windows 任务管理器中的 GPU 是否有计算负载。

结果保存在：

```text
outputs\plain20\seed42_5epochs\
runs\plain20\seed42_5epochs\
```

## 六、训练 ResNet-20

PlainNet-20 完成并记录结果后，在 Prompt A 执行：

```bat
python train.py --model resnet20 --epochs 5
```

结果保存在：

```text
outputs\resnet20\seed42_5epochs\
runs\resnet20\seed42_5epochs\
```

如果同名实验目录已经包含文件，程序会拒绝覆盖。需要重新实验时使用新的名称，例如：

```bat
python train.py --model resnet20 --epochs 5 --run-name seed42_retry
```

## 七、输出文件分别是什么

| 文件 | 含义 |
|---|---|
| `config.yaml` | 本次模型、数据、优化器和路径配置 |
| `history.csv` | 每个完整 epoch 的训练/测试指标 |
| `latest.pt` | 最近一个完整 epoch 的恢复点 |
| `best.pt` | 测试准确率最高时的恢复点 |
| `runs\...` 中的 event 文件 | TensorBoard 读取的训练日志 |

## 八、中断与恢复

按 `Ctrl+C` 时：

- 当前尚未结束的 epoch 不保存；
- 上一个完整 epoch 的 `latest.pt` 和 `history.csv` 保留；
- 程序会打印恢复命令。

PlainNet-20 恢复示例：

```bat
python train.py --model plain20 --epochs 5 --resume "outputs\plain20\seed42_5epochs\latest.pt"
```

ResNet-20 恢复示例：

```bat
python train.py --model resnet20 --epochs 5 --resume "outputs\resnet20\seed42_5epochs\latest.pt"
```

恢复粒度是完整 epoch，不是 epoch 中间的某个 batch。

## 十、对比时要回答的问题

1. 两个模型的训练 loss 是否都从较高值下降？
2. 哪个模型的训练 loss 下降更快、更平稳？
3. 哪个模型在相同 5 轮内获得更高的测试准确率？
4. 训练准确率提升而测试准确率停滞时，是否已经出现过拟合迹象？
5. ResNet-20 的优势是否足够明显，值得进入更长日程？
6. 如果 5 轮结论不明显，是模型无效，还是训练时间过短？

最后一个问题很重要：5 轮预实验的目的主要是证明整条训练流程有效并观察早期趋势，不能单凭它否定论文结论。
