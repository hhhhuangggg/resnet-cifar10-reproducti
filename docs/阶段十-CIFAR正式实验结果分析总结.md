# 阶段十：CIFAR-10 正式实验结果分析总结

## 1. 本阶段做了什么

本阶段没有重新训练模型，而是对已经完成的四组 64k iteration 正式实验进行统一、可复查的结果分析：

- PlainNet-20
- ResNet-20
- PlainNet-56
- ResNet-56

分析程序只读取原始实验目录中的 `config.yaml` 和 `history.csv`，不会修改 checkpoint、训练日志或原始结果。程序先验证四组实验是否采用相同训练条件，再计算指标并生成汇总表和图表。

## 2. 为什么要先检查实验公平性

只有控制训练条件一致，PlainNet 与 ResNet 的结果差异才主要来自网络结构。程序要求四组实验同时满足：

| 配置项 | 固定值 |
|---|---:|
| schedule | `paper` |
| seed | 42 |
| batch size | 128 |
| max iterations | 64000 |
| 学习率 | 0.1 → 0.01 → 0.001 |
| 学习率变化点 | 32000、48000 iterations |

如果某一组实验使用了不同随机种子、batch size、训练长度或学习率方案，程序会停止分析，而不是把不公平的数据放进同一张图。

## 3. 指标是怎样计算的

### 3.1 准确率与错误率

论文主要使用测试错误率，因此本阶段统一换算为：

```text
错误率（%） = 100 × (1 - accuracy)
```

例如，测试准确率为 91.93%，对应测试错误率为：

```text
100% - 91.93% = 8.07%
```

### 3.2 最佳结果与最终结果

这两个概念不能混用：

- 最佳测试结果：整个训练过程中测试准确率最高的那次评估。
- 最终结果：第 64000 次参数更新结束后的那次评估。

最佳值适合与论文报告的最佳测试错误率对照；最终值可以观察训练结束时模型处于什么状态。程序同时保留二者，避免只挑最好结果而丢失训练末尾信息。

## 4. 四组实验结果

| 模型 | 参数量 | 最佳测试错误率 | 最终训练错误率 | 最终测试错误率 | 总用时 |
|---|---:|---:|---:|---:|---:|
| PlainNet-20 | 269,722 | 9.30% | 1.12% | 9.35% | 62.43 分钟 |
| ResNet-20 | 269,722 | 8.07% | 0.61% | 8.23% | 64.00 分钟 |
| PlainNet-56 | 853,018 | 12.03% | 3.75% | 12.32% | 92.44 分钟 |
| ResNet-56 | 853,018 | 6.92% | 0.06% | 7.13% | 101.21 分钟 |

四组实验都完成了 64000 iterations。PlainNet 与同深度 ResNet 的参数量相同，因此对比不是靠增加参数获得优势，而是观察 shortcut 对优化过程的影响。

## 5. 最重要的对比

### 5.1 PlainNet 加深后发生退化

```text
12.03% - 9.30% = 2.73 个百分点
```

PlainNet 从 20 层加深到 56 层后，最佳测试错误率反而增加 2.73 个百分点。更深网络没有自动得到更好的结果。

更关键的是，PlainNet-56 的最终训练错误率为 3.75%，也高于 PlainNet-20 的 1.12%。因此这不只是“训练集拟合得更好，但测试集变差”的普通过拟合现象；更深的 PlainNet 连训练集本身都优化得更差。这正是 ResNet 论文希望说明的 degradation problem（退化问题）。

### 5.2 ResNet 加深后继续改善

```text
8.07% - 6.92% = 1.15 个百分点
```

ResNet 从 20 层加深到 56 层后，最佳测试错误率降低 1.15 个百分点。ResNet-56 最终训练错误率仅为 0.06%，说明更深残差网络能够把训练目标优化到很低。

### 5.3 56 层网络中 shortcut 的作用最明显

```text
12.03% - 6.92% = 5.11 个百分点
```

相同深度、相同参数量和相同训练设置下，ResNet-56 比 PlainNet-56 的最佳测试错误率低 5.11 个百分点。这说明 shortcut 没有简单地扩大模型规模，而是改变了信息和梯度传播路径，显著缓解了深层网络的优化困难。

## 6. 与论文结果对比

| 模型 | 论文测试错误率 | 本次最佳测试错误率 | 本次相对论文 |
|---|---:|---:|---:|
| ResNet-20 | 8.75% | 8.07% | 低 0.68 个百分点 |
| ResNet-56 | 6.97% | 6.92% | 低 0.05 个百分点 |

ResNet-20 和 ResNet-56 均非常接近论文结果，并且本次单次实验的数值略低。这里的“更低”表示测试错误率更低，但不能据此声称全面超过论文，因为论文结果涉及其特定实现、实验环境和统计方式，本次目前只有一个随机种子。

论文表格没有给出可直接逐项引用的 PlainNet 精确测试错误率，所以 PlainNet 部分主要用于复现论文所展示的趋势：PlainNet 加深后训练和测试表现都恶化，而 ResNet 加深后继续改善。

## 7. 如何阅读错误率曲线

错误率曲线图分为上下两个区域：

- 上图是训练错误率，用于判断模型能否把训练数据优化好。
- 下图是测试错误率，用于判断模型对未参与参数更新的数据的分类表现。
- 32000 和 48000 处的灰色虚线是学习率降低的位置。
- 64000 处的黑色点线是正式训练结束位置。
- 曲线使用 `history.csv` 原始评估点，没有做平滑、插值或删点。

曲线中能够直接观察到：

1. PlainNet-56 在整个前期优化阶段明显落后。
2. 每次降低学习率后，四个模型的错误率都会出现明显下降。
3. ResNet-56 后期训练错误率接近 0，同时测试错误率保持四组中最低。
4. PlainNet-56 即使训练到 64k，训练错误率仍明显高于其他模型。

## 8. 当前结论的边界

本阶段已经能够证明本次代码和训练流程复现了论文的核心趋势，但仍有以下限制：

- 当前每个模型只使用 seed 42 训练一次，不能计算多次运行的均值和标准差。
- 目前只比较 20 层与 56 层，是深度序列的两个端点。
- PlainNet-32/44 和 ResNet-32/44 尚未正式训练，因此还不能画出完整的 20/32/44/56 深度趋势。
- 本阶段复现的是 CIFAR-10 实验，不等同于 ImageNet 上的 ResNet-18/34/50/101/152 训练结果。
- 小幅优于论文的单次结果可能来自随机波动、软件实现或硬件环境差异，不能脱离重复实验做过度解释。

## 10. 可直接用于日报的总结

今日完成 CIFAR-10 正式实验结果分析模块。首先对 PlainNet-20、ResNet-20、PlainNet-56 和 ResNet-56 四组 64k iteration 实验的模型名称、随机种子、batch size、训练长度及学习率策略进行了自动一致性校验；随后从原始 `history.csv` 中分别提取最佳与最终训练指标，生成汇总 CSV、训练/测试错误率曲线和论文对比图。实验结果显示，PlainNet 从 20 层加深到 56 层后最佳测试错误率由 9.30% 上升至 12.03%，且最终训练错误率也由 1.12% 上升至 3.75%，复现了深层普通网络的退化问题；ResNet 从 20 层加深到 56 层后最佳测试错误率由 8.07% 降至 6.92%，说明 shortcut 有效缓解了深层网络的优化困难。ResNet-20 和 ResNet-56 与论文结果分别相差 0.68 和 0.05 个百分点，整体复现趋势和数值均符合预期。
