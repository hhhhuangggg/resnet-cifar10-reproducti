# 阶段十三：四模型最终结果分析总结

## 1. 为什么本阶段只保留 20 层和 56 层

最初路线包含 PlainNet/ResNet-20、32、44、56。后续根据复现目标和训练成本，最终取消 32/44 层正式训练，也不继续多随机种子、ResNet-110/1202 或 ImageNet 训练。

因此，本阶段不再追求完整的四深度序列，而是使用两个具有代表性的端点：

- 20 层：较浅网络；
- 56 层：明显更深的网络。

每个深度同时训练 PlainNet 和 ResNet，形成四组实验：

| 深度 | 无 shortcut | 有 shortcut |
|---|---|---|
| 20 | PlainNet-20 | ResNet-20 |
| 56 | PlainNet-56 | ResNet-56 |

这种设计仍然能够回答核心问题：普通网络加深后是否出现退化，以及 residual shortcut 是否能够缓解这种优化困难。

## 2. 四组实验的公平性

分析程序读取每个实验的 `config.yaml`，要求影响比较公平性的训练设置完全一致：

| 配置 | 固定值 |
|---|---:|
| 数据集 | CIFAR-10 |
| seed | 42 |
| batch size | 128 |
| schedule | `paper` |
| max iterations | 64000 |
| 初始学习率 | 0.1 |
| 学习率变化点 | 32000、48000 |
| 后续学习率 | 0.01、0.001 |

程序还检查 `history.csv`：

- 必须包含固定字段；
- iteration 必须严格递增；
- 最后一条记录必须位于 64000；
- 最后一个 epoch 必须是为到达 64000 而形成的 partial epoch。

如果任意一组设置不同或训练没有完成，分析会直接停止。

## 3. 最佳值与最终值的区别

### 最佳测试结果

训练过程中测试准确率最高的评估点。与论文最佳测试错误率对比时使用这个值。

### 最终结果

第 64000 次参数更新结束后的测试结果。它反映训练结束时模型的状态，但不一定恰好是全过程最好的一次。

本阶段同时保留：

- 最佳测试准确率和错误率；
- 最终训练准确率和错误率；
- 最终测试准确率和错误率；
- 最佳值所在 epoch 和 iteration；
- 总训练时间。

这样可以避免只报告最好的一个数字，而忽略训练结束状态。

## 4. 四模型正式结果

| 模型 | 参数量 | 最佳测试错误率 | 最终训练错误率 | 最终测试错误率 | 总时间 |
|---|---:|---:|---:|---:|---:|
| PlainNet-20 | 269,722 | 9.30% | 1.12% | 9.35% | 62.43 分钟 |
| ResNet-20 | 269,722 | 8.07% | 0.61% | 8.23% | 64.00 分钟 |
| PlainNet-56 | 853,018 | 12.03% | 3.75% | 12.32% | 92.44 分钟 |
| ResNet-56 | 853,018 | 6.92% | 0.06% | 7.13% | 101.21 分钟 |

同一深度的 PlainNet 和 ResNet 参数量相同，因此 shortcut 的优势不能简单解释为“ResNet 参数更多”。

## 5. PlainNet 退化证据

PlainNet 从 20 层加深到 56 层：

```text
12.03% - 9.30% = 2.73 个百分点
```

更深的 PlainNet-56 最佳测试错误率反而高 2.73 个百分点。

同时：

```text
PlainNet-20 最终训练错误率 = 1.12%
PlainNet-56 最终训练错误率 = 3.75%
```

PlainNet-56 不仅测试更差，训练集本身也没有 PlainNet-20 优化得好。因此这不是普通的过拟合：

```text
普通过拟合：训练更好，测试更差
本次退化：训练更差，测试也更差
```

这与 ResNet 论文中的 degradation problem 含义一致：增加网络深度后，理论表达能力没有降低，但优化算法更难找到至少与浅层网络相当的解。

## 6. ResNet 加深后的改善

ResNet 从 20 层加深到 56 层：

```text
8.07% - 6.92% = 1.15 个百分点
```

测试错误率降低 1.15 个百分点。与 PlainNet 相反，残差网络能够从增加深度中获得改善。

ResNet-56 最终训练错误率只有约 0.06%，说明网络能够将训练目标优化到非常低。shortcut 为信息和梯度提供了更直接的传播路径，使深层网络更容易学习相对 identity mapping 的残差。

## 7. shortcut 在 56 层网络中的作用

在相同 56 层深度下：

```text
PlainNet-56 = 12.03%
ResNet-56   =  6.92%
差值        =  5.11 个百分点
```

Residual shortcut 带来 5.11 个百分点的最佳测试错误率改善。

这里的 shortcut 是每个 residual block 的第二条路径。主路径学习变换 \(F(x)\)，shortcut 传递 \(x\)，输出为：

```text
y = F(x) + x
```

在尺寸或通道变化时，本项目的 CIFAR ResNet 使用论文 Option A，通过下采样和零填充匹配形状，不引入额外可训练投影参数。这保证了与 PlainNet 的参数量公平比较。

## 8. 与论文结果对比

| 模型 | 论文测试错误率 | 本次最佳测试错误率 | 差异 |
|---|---:|---:|---:|
| ResNet-20 | 8.75% | 8.07% | 本次低 0.68 个百分点 |
| ResNet-56 | 6.97% | 6.92% | 本次低 0.05 个百分点 |

本次 ResNet-20/56 与论文数值接近，并复现了“网络加深后 ResNet 继续改善”的趋势。

“本次错误率更低”不等于已经证明全面超过论文，因为当前只有单个随机种子；不同实现、随机初始化、软件版本和硬件环境都会造成波动。

论文没有在相同结果表中给出可直接引用的 PlainNet 精确数字，因此 PlainNet 主要用于验证退化趋势，不虚构论文 PlainNet 数值。

## 10. 当前结论边界

最终范围不包含：

- PlainNet/ResNet-32 和 44 正式训练；
- 多随机种子均值与标准差；
- ResNet-110/1202；
- ImageNet 数据集训练；
- ImageNet 预训练权重；
- 在 ImageNet 上与论文准确率对比。

因此可以说：

> 本次四模型实验复现了 PlainNet 加深后的退化趋势，以及 residual shortcut 缓解深层网络优化困难的核心现象。

不能说：

> 已经完成论文全部深度、全部随机重复或 ImageNet 训练结果的完全复现。

## 12. 本阶段学到了什么

1. 论文复现不只是得到一个准确率，还要保证比较条件一致。
2. 最佳指标和最终指标回答不同问题，应该分别保存。
3. 只看测试误差不能区分过拟合和优化退化，还要同时观察训练误差。
4. PlainNet-56 训练误差也更高，是退化问题的重要证据。
5. shortcut 的主要价值不仅是表达能力，更是让深层网络更容易优化。
6. 取消部分实验后，报告必须同步收缩结论边界。

## 13. 可直接用于日报的总结

今日完成第十三阶段四模型正式结果固化。分析程序从原始 `E:\文档\resnet复现\outputs` 只读加载 PlainNet-20、ResNet-20、PlainNet-56 和 ResNet-56 的 seed 42、64000 iteration 实验，重新校验训练配置与历史完整性，并生成汇总 CSV、训练/测试错误率曲线及论文对比图。结果显示 PlainNet 从 20 层加深到 56 层后最佳测试错误率由 9.30% 上升到 12.03%，退化 2.73 个百分点，并且训练错误率也由 1.12% 上升到 3.75%，说明问题不是普通过拟合；ResNet 从 20 层到 56 层错误率由 8.07% 降至 6.92%，改善 1.15 个百分点；在 56 层相同参数规模下，shortcut 相对 PlainNet 改善 5.11 个百分点。本阶段明确将结论限定为 20/56 层端点对比，不包含 32/44、多 seed、110/1202 或 ImageNet 训练。
